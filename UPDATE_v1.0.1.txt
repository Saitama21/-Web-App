ХОЧУ v1.0.1 — исправление автоподтягивания товаров

Что изменено:
1. Rozetka:
   - отдельный fallback по ID товара;
   - попытка получить название, цену и фото без загрузки витрины;
   - сырой HTTP 403 больше не показывается пользователю.

2. Makeup / JS-защищённые магазины:
   - расширенный JSON-LD / OpenGraph / DOM / embedded JSON parser;
   - резервное чтение через внешние metadata/readability fallback;
   - если получена только часть данных, интерфейс сообщает об этом честно.

3. Категории:
   - Makeup -> Красота
   - Converse -> Одежда и обувь
   - ALLO / COMFY / Фокстрот -> Техника
   - для маркетплейсов категория определяется только когда название товара достаточно однозначное.

4. Интерфейс:
   - магазин определяется уже при вставке ссылки;
   - после успешного чтения кнопка меняется с «Подтянуть» на «Обновить»;
   - сообщения теперь: полный успех / частичные данные / ручное заполнение;
   - превью карточки обновляется сразу.

5. Cache:
   - service worker переведён на новый cache v1.0.1 и удаляет старый frontend cache.

Для обновления Railway:
замени файлы проекта содержимым этой сборки, Commit -> Push.
Railway пересоберёт приложение автоматически.
