# Android: добавить товар через «Поделиться»

В `manifest.webmanifest` уже настроен Web Share Target.

1. После деплоя v1.6.0 открой «Хочу» в Chrome на Android.
2. Установи приложение через меню Chrome → **Установить приложение** / **Добавить на главный экран**.
3. Открой товар в браузере или приложении магазина.
4. Нажми **Поделиться** → **Хочу**.

Android передаст заголовок, текст и URL в `/share-target`. Приложение выберет первую безопасную `http/https`-ссылку, удалит параметры из адресной строки, сохранит её до входа и один раз запустит обычный парсер товара.

Если «Хочу» не появилось в меню сразу после обновления, удали старую установленную PWA и установи её заново: Android регистрирует Share Target в момент установки.
