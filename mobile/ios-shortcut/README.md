# Команда iPhone/iPad «В Хочу»

Эта команда работает из Safari и из приложений магазинов, которые передают обычную ссылку. Она не содержит пароль или API-ключ.

## Собери команду один раз

1. Открой приложение **Команды** → `+` → назови команду **В Хочу**.
2. Открой сведения команды и включи **Показывать на странице экспорта**.
3. Во входных типах оставь **URL-адреса**, **веб-страницы Safari** и **текст**.
4. Добавь действия строго в таком порядке:
   1. **Получить URL-адреса из входных данных команды**.
   2. **Получить элемент из списка** → `Первый элемент`.
   3. **Кодировать URL** → кодировать полученный URL.
   4. **Текст** со строкой ниже; вместо `[Кодированный URL]` вставь магическую переменную предыдущего действия:

      ```text
      https://web-app-production-22f3.up.railway.app/add?source=ios-shortcut&share_url=[Кодированный URL]
      ```

   5. **URL** — преобразовать текст в URL.
   6. **Открыть URL-адреса**.
5. Сохрани команду.

## Использование

На странице товара нажми **Поделиться** → **В Хочу**. Приложение откроет новую карточку, удалит служебную ссылку из адресной строки и один раз нажмёт «Подтянуть» автоматически. Если вход в «Хочу» ещё не выполнен, ссылка сохранится до авторизации.

## Важно

- «Открыть URL» использует системный браузер. iOS не гарантирует переход именно в установленный значок PWA без нативного контейнера и Universal Links.
- Подписанный `.shortcut` экспортирует само приложение «Команды». После ручной сборки нажми «Поделиться» → «Копировать ссылку iCloud», чтобы раздавать установку одной ссылкой.
- Для максимальной точности в Safari используй Safari Web Extension: оно передаёт уже видимые DOM-данные и не запускает AI для подтверждённой цены.
