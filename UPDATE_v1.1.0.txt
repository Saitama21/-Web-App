ХОЧУ v1.1.0 — MULTI-ACCOUNT

- Отдельные аккаунты и отдельные хотелки для каждого пользователя.
- Регистрация только по invite-ссылке + одобрение администратора.
- Админ-панель: заявки, пользователи, блокировка, удаление, приглашения.
- Сброс пароля через одноразовую ссылку; администратор пароль не видит.
- Серверные сессии и мгновенное завершение сессий при блокировке.
- Автоматическая миграция старых хотелок на аккаунт администратора.
- Пароли: scrypt + уникальная соль.
- Invite/reset токены хранятся в БД только в виде хешей.
