ХОЧУ v1.1.2 — AUTH + CACHE FIX

Исправлено:
- формы входа больше не зависят от старого cached app.js;
- styles.css и app.js подключаются с версией v1.1.2;
- Service Worker больше не кэширует HTML/JS/CSS и удаляет старые hochu-shell caches;
- frontend читает логин/пароль через FormData и явно отправляет JSON;
- backend принимает JSON и urlencoded формы;
- ADMIN_NAME / ADMIN_USERNAME / ADMIN_EMAIL / ADMIN_PASSWORD синхронизируются с существующим admin в PostgreSQL при старте;
- ADMIN_PASSWORD автоматически перехешируется, если старый пароль в БД отличается;
- frontend-статика отдается с no-store на время активной разработки.

После деплоя Railway:
1. дождаться Successful;
2. открыть сайт;
3. один раз Ctrl+Shift+R / Cmd+Shift+R;
4. войти ADMIN_USERNAME (или ADMIN_EMAIL) + ADMIN_PASSWORD.
