ХОЧУ v1.1.0 — БЫСТРОЕ ОБНОВЛЕНИЕ RAILWAY

1. В Railway -> Variables добавь ДО первого запуска v1.1.0:

ADMIN_NAME=Иван
ADMIN_USERNAME=ivan
ADMIN_EMAIL=твой_email
ADMIN_PASSWORD=твой_пароль

Если в старом проекте уже есть APP_PASSWORD, он служит запасным ADMIN_PASSWORD при первой миграции.

2. PostgreSQL НЕ удаляй. DATABASE_URL оставь как есть.

3. Замени файлы репозитория содержимым архива v1.1.0.

4. Commit -> Push.

5. Railway пересоберёт проект и сам выполнит миграцию базы.

6. Проверь:
   https://ТВОЙ-ДОМЕН/api/health

Должно быть:
   version: 1.1.0
   database: postgresql
   adminReady: true

7. Вход администратора:
   логин: значение ADMIN_USERNAME (или ADMIN_EMAIL)
   пароль: ADMIN_PASSWORD

8. Администрирование -> Создать приглашение -> отправь ссылку другу.

9. Друг создаёт логин/email/пароль -> ты одобряешь заявку -> у него появляется собственный приватный список.

ВАЖНО:
- пароли пользователей администратор не видит;
- для сброса пароля администратор создаёт одноразовую ссылку;
- старые хотелки из v1.0.x автоматически останутся у администратора.
