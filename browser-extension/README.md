# «В Хочу» для Chrome на Mac

1. Распакуй архив проекта.
2. Открой в Chrome `chrome://extensions`.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение» и выбери папку `browser-extension`.
5. На открывшейся странице вставь адрес своего приложения «Хочу» и сохрани.
6. Закрепи значок расширения возле адресной строки.
7. Открой карточку товара, дождись цены и нажми «В Хочу».

Расширение использует только разрешение `activeTab`: оно читает одну активную страницу исключительно после нажатия на значок. Пароль, Railway Variables и OpenAI API-ключ расширению не передаются.
