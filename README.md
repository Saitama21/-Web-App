# Хочу v1.1.9

Веб-приложение личных списков покупок с мультиаккаунтами, админ-доступом и автоподтягиванием карточек магазинов.

## v1.1.9 — Makeup Product Gallery Fix

- MAKEUP: главное фото берётся прежде всего из товарной галереи / Product JSON-LD.
- При антибот-защите используется точная карточка поиска MAKEUP по product ID и названию; её изображение имеет приоритет над баннерами страницы.
- Квадратные рекламные блоки больше не выигрывают только из-за подходящих пропорций.
- Усилена проверка alt/context: promo, подарок, акция, дермакосметика и другие рекламные кандидаты штрафуются или отбрасываются.
- Цена, вариант/объём, аккаунты и база данных не менялись.
- Бренд-иконка из v1.1.8 сохранена.

## Проверка

В проекте есть `tests/makeup-image-parser.test.mjs`. После `npm install` можно запустить:

```bash
npm run test:parser
```

## Railway

Проект запускается командой `npm start` и использует `DATABASE_URL` для PostgreSQL.
