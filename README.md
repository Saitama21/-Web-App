# Хочу — v1.2.2

## Universal Product Image Resolver

Версия исправляет выбор изображения товара для обычных интернет-магазинов без добавления отдельного парсера под каждый домен.

### Что изменено

- Приоритет у структурированных данных `Product` / JSON-LD и изображений из галереи карточки товара.
- Поддерживаются `src`, `srcset`, `data-src`, `data-original`, `data-zoom-image`, `data-large-image` и ссылки на оригиналы.
- Кандидаты ранжируются по связи с названием товара и DOM-контексту (`product`, `gallery`, `slider`, `zoom` и т. п.).
- Баннеры, promo/sale, логотипы, иконки, блоки доставки/гарантии, рекомендации и похожие товары получают сильный штраф.
- Для лучших кандидатов сервер проверяет реальные размеры изображения; слишком узкие/широкие рекламные полосы отбрасываются.
- `og:image` теперь fallback, а не безусловный победитель.
- Существующие специальные парсеры Rozetka и Makeup сохранены. Makeup продолжает использовать свой SKU-aware resolver.
- Режим цены из v1.2.1 сохранён: фонового мониторинга нет; цена меняется только вручную.

### Проверки

`tests/generic-image-ranking.test.mjs` проверяет:

1. JSON-LD Product против promo `og:image`;
2. product gallery против квадратного рекламного изображения;
3. выбор максимального `srcset`;
4. штраф панорамным баннерам;
5. чтение размеров изображения;
6. кейс Touch / Huion Kamvas 13 Gen3 Black.

Запуск:

```bash
npm run test:image
```

Для полного запуска приложения нужны зависимости из `package.json` (`npm install`). Railway устанавливает их при деплое автоматически.

### Railway / PostgreSQL

Новых переменных окружения и SQL-миграций для v1.2.2 нет.
