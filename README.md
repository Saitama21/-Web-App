# Хочу v1.2.4

Личный журнал желаний и покупок для Railway + PostgreSQL.

## Что изменилось в v1.2.4

- Добавлен **AI-инспектор товара** на OpenAI Responses API. По умолчанию используется `gpt-5.6-terra`.
- Инспектор работает только во время ручного действия **«Подтянуть»** и не запускает фоновый мониторинг цен.
- Обычный парсер по-прежнему собирает данные первым. AI получает только ограниченный набор кандидатов и выбирает среди них:
  - главное фото товара вместо баннера/рекламы;
  - текущую цену вместо старой зачёркнутой;
  - выбранный объём/размер/вариант, если он присутствует в данных страницы.
- Для изображений AI может визуально сравнить несколько кандидатов. Изображения отправляются с низкой детализацией, чтобы уменьшить расход API.
- AI не может придумать произвольный URL/цену/вариант: Structured Outputs ограничивает ответ индексами уже найденных кандидатов. При ошибке OpenAI API сохраняется результат обычного парсера.
- В Настройках появился индикатор состояния AI-инспектора.
- На мобильной версии добавлена компактная плашка **«Хочу · v1.2.4»** с иконкой приложения.
- Нижний мобильный dock закреплён у нижнего safe-area, плавно скрывается при прокрутке вниз и возвращается при прокрутке вверх/касании нижней зоны экрана.
- Сохранены аватарки профиля, Manual Price Mode и все предыдущие функции v1.2.3.

## Railway

Основные переменные:

```env
DATABASE_URL=...
SESSION_SECRET=...
ADMIN_NAME=Иван
ADMIN_USERNAME=...
ADMIN_EMAIL=...
ADMIN_PASSWORD=...
```

Для AI-инспектора добавь в **Railway → Variables**:

```env
OPENAI_API_KEY=sk-...
AI_INSPECTOR_ENABLED=true
AI_INSPECTOR_MODEL=gpt-5.6-terra
AI_INSPECTOR_MAX_IMAGES=4
```

`OPENAI_API_KEY` хранится только на сервере и не отправляется в браузер. Не добавляй реальный ключ в GitHub.

Если `OPENAI_API_KEY` отсутствует или API временно недоступен, «Хочу» продолжает работать на обычном парсере.
