# Хочу — v1.2.1

Личный журнал желаний и покупок с приватными аккаунтами, накоплениями, сохранёнными ценами и прямым переходом в магазин.

## Новое в v1.2.1

- Для уже добавленной хотелки автоматическое/ручное подтягивание цены из редактора отключено.
- В карточке товара появилась кнопка **«↗ Перейти на сайт»** — открывает исходную страницу магазина в новой вкладке.
- Цена остаётся такой, какой была сохранена в «Хочу», пока пользователь сам не изменит её вручную.
- Автоматического фонового мониторинга цен нет.
- При добавлении **новой** хотелки кнопка «Подтянуть» остаётся: она нужна только для первичного заполнения карточки по ссылке.
- История цены сохраняется и пополняется только при ручном изменении цены пользователем.

## Уже есть

- Мультиаккаунты и приватные списки по `user_id`.
- Администратор, приглашения, заявки, блокировка и сброс пароля.
- Категории, магазины, статусы и статистика.
- Поле «Накопил», прогресс и расчёт «Осталось накопить».
- История сохранённых цен с графиком.
- Парсеры Rozetka и Makeup для первичного добавления товара.
- Светлая/тёмная glass-тема.
- PWA и инструкция установки на iPhone/iPad и Android.

## PostgreSQL

Существующая схема v1.2.0 совместима. Новых ручных SQL-миграций для v1.2.1 не требуется.

## Railway

Запуск: `npm start`. База — `DATABASE_URL`. Переменные администратора: `ADMIN_NAME`, `ADMIN_USERNAME`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, плюс `SESSION_SECRET`.
