# Хочу v1.3.1

Личный журнал желаний и покупок для Railway + PostgreSQL.

## Что изменилось в v1.3.1

- Исправлен Touch: серверные Product/Offer-данны больше не могут оставить в карточке старую зачёркнутую цену.
- Для Touch добавлена обязательная перепроверка отрисованной карточки, даже если первый ответ уже содержит название, картинку и одну цену.
- Добавлен тест реальной акционной связки Touch `21 599 − 6 350 = 15 249`.

## Что было добавлено в v1.3.0

- Добавлен **бесплатный детерминированный контроль цены** до обращения к AI.
- Распознаётся типичная акционная связка: старая зачёркнутая цена → размер скидки → фактическая текущая цена.
- Сервер проверяет арифметику без токенов OpenAI, например `21 599 − 7 100 = 14 499`.
- Если арифметика подтверждена, текущая цена получает статус `VERIFIED` и **блокируется от перезаписи AI**.
- Зачёркнутая цена и сумма скидки хранятся отдельно и отображаются в карточке товара.
- Основной AI-инспектор переключён на дешёвый `gpt-5-mini`.
- `gpt-5.6-terra` используется как fallback только при конфликте/неоднозначной цене.
- Кандидаты цен получают роли `current`, `old`, `discount`; AI запрещено выбирать `old` или `discount` как фактическую цену.
- Structured Outputs остаются включены: модель выбирает только из уже найденных кандидатов.
- При ручном изменении цены отметка автоматической проверки очищается, чтобы старая верификация не выглядела действующей.

## Railway

Основные переменные:

```env
DATABASE_URL=...
SESSION_SECRET=...
ADMIN_NAME=Иван
ADMIN_USERNAME=...
ADMIN_EMAIL=...
ADMIN_PASSWORD=...
```

Для AI-инспектора добавь в **Railway → Variables**:

```env
OPENAI_API_KEY=sk-...
AI_INSPECTOR_ENABLED=true
AI_INSPECTOR_MODEL=gpt-5-mini
AI_INSPECTOR_FALLBACK_MODEL=gpt-5.6-terra
AI_INSPECTOR_MAX_IMAGES=4
```

`OPENAI_API_KEY` хранится только на сервере и не отправляется в браузер. Не добавляй реальный ключ в GitHub.

Если `OPENAI_API_KEY` отсутствует или API временно недоступен, «Хочу» продолжает работать на обычном парсере.
