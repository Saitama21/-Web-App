# Хочу — Web App v1.0.0

Личный журнал желаний, покупок и накоплений. Сборка подготовлена для GitHub + Railway.

## Что уже работает

- Светлая **матовая стеклянная** тема.
- Тёмная **графитовая стеклянная** тема.
- Зелёно-мятный акцент вместо фиолетового.
- Авто/системная тема.
- Полная адаптация под desktop / tablet / mobile.
- PWA: можно добавить приложение на главный экран iPhone/iPad/Android.
- Вход по личному паролю.
- PostgreSQL на Railway; локально есть временный memory fallback.
- Добавление, изменение и удаление покупок.
- Поля: ссылка, название, цена, **накопил**, категория, приоритет, статус, магазин, фото, заметка.
- Автоматическая попытка подтянуть название / изображение / цену / магазин из ссылки.
- Прогресс накопления по каждому товару и по всему списку.
- Статусы: `Хочу`, `Планирую`, `Заказал`, `Куплено`, `Отложено`.
- Категории, магазины, статистика, поиск, сортировка и фильтры.
- Известные магазины: Rozetka, Makeup, Converse, ALLO, COMFY, Фокстрот, Епіцентр; остальные определяются по домену.
- `/api/health` для Railway Health Check.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
APP_PASSWORD=1234 SESSION_SECRET=local-test npm start
```

Открыть: `http://localhost:3000`

Без `DATABASE_URL` данные хранятся только в памяти процесса и исчезнут после перезапуска. Это специально для локального теста.

## Деплой на Railway через GitHub Desktop

1. Распакуй архив в отдельную папку.
2. В **GitHub Desktop**: `File → Add Local Repository` или создай новый репозиторий из этой папки.
3. Сделай Commit и `Publish repository` / `Push origin`.
4. В Railway: **New Project → Deploy from GitHub Repo** и выбери репозиторий.
5. В этом же Railway Project добавь базу: **+ New → Database → PostgreSQL**.
6. В сервисе веб-приложения открой **Variables** и добавь:

```env
APP_PASSWORD=твой_пароль
SESSION_SECRET=длинная_случайная_строка
```

7. Свяжи `DATABASE_URL` PostgreSQL с веб-сервисом. В Railway это можно сделать через reference variable на `DATABASE_URL` базы.
8. Railway сам использует `npm start` из `railway.json`.
9. В `Settings → Networking` нажми **Generate Domain**.

## Проверка после деплоя

Открой:

```text
https://ТВОЙ-ДОМЕН.up.railway.app/api/health
```

Рабочий вариант с базой выглядит примерно так:

```json
{
  "ok": true,
  "app": "Хочу",
  "version": "1.0.0",
  "database": "postgresql"
}
```

Если увидишь `"database":"memory"`, веб-приложение работает, но PostgreSQL ещё не подключён.

## Автоподтягивание товара по ссылке

Сервер читает OpenGraph / JSON-LD данные страницы. Некоторые магазины используют Cloudflare или другую anti-bot защиту и могут не дать прочитать карточку. В этом случае приложение **не ломается**: ссылка остаётся, а название, цену, магазин и фото можно заполнить вручную.
