# Хочу v1.1.10

Веб-приложение личных списков покупок с мультиаккаунтами, админ-доступом и автоподтягиванием карточек магазинов.

## v1.1.10 — Mobile Install Guide

- В «Настройки / Профиль» добавлен раздел «Установить «Хочу»».
- Встроена пошаговая инструкция для iPhone/iPad и Android.
- На Android используется системный `beforeinstallprompt`, когда браузер разрешает прямую установку.
- На iPhone определяется Safari и показывается подсказка «Поделиться → На экран Домой».
- Если приложение уже запущено в standalone-режиме, интерфейс показывает статус «Уже установлено».
- Функционал покупок, аккаунтов и парсеров не изменён.

## Проверка

В проекте есть `tests/makeup-image-parser.test.mjs`. После `npm install` можно запустить:

```bash
npm run test:parser
```

## Railway

Проект запускается командой `npm start` и использует `DATABASE_URL` для PostgreSQL.
