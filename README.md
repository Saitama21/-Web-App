# Хочу v1.2.3

Личный журнал желаний и покупок для Railway + PostgreSQL.

## Что изменилось в v1.2.3

- Универсальный выбор **актуальной цены**: старая/зачёркнутая цена и размер скидки больше не должны выигрывать у текущей цены. Поддерживается типичный формат `старая цена → скидка → новая цена`.
- Универсальный выбор **главного изображения товара**: приоритет Product JSON-LD, product gallery, original/zoom/srcset и embedded product JSON; рекламные `/upload/rk/`, banner/promo/logo и служебные изображения сильно понижаются.
- Улучшен reader fallback для магазинов, которые плохо отдают HTML серверу.
- В левом бренд-блоке появилась плашка с текущей версией приложения.
- Пользователи могут загрузить, заменить и удалить **аватар профиля** в Настройках. Изображение уменьшается в браузере и хранится в PostgreSQL, поэтому не зависит от временной файловой системы Railway.
- Аватар отображается в профиле и в списке пользователей администратора; без аватара остаются инициалы.
- Сохранён Manual Price Mode: фонового мониторинга цен нет.

## Railway

Переменные окружения те же:

```env
DATABASE_URL=...
SESSION_SECRET=...
ADMIN_NAME=Иван
ADMIN_USERNAME=...
ADMIN_EMAIL=...
ADMIN_PASSWORD=...
```

Миграция `users.avatar` выполняется автоматически при запуске. Ручной SQL не нужен.
