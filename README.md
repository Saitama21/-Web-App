# Хочу v1.1.6

Личный журнал желаний с мультиаккаунтами и администрированием.

## Деплой через GitHub Desktop → Railway

1. Распакуй ZIP прямо в корень локального репозитория.
2. Разреши Finder заменить существующие файлы.
3. В GitHub Desktop проверь Changes.
4. Commit to main → Push origin.
5. Railway автоматически пересоберёт приложение.

## Railway Variables

Обязательные переменные:

- `DATABASE_URL`
- `SESSION_SECRET`
- `ADMIN_NAME`
- `ADMIN_USERNAME`
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`

## v1.1.6

Исправлено определение цены на Makeup для товаров с несколькими объёмами/SKU. Парсер сначала читает карточку товара, затем пробует альтернативную языковую версию страницы и, если цена всё ещё не найдена, ищет точную карточку по product ID в поисковой выдаче Makeup. Общие минимальные цены семейства товара не используются как цена выбранного варианта.

Фото товара и поле «Вариант / объём» сохранены. Для Makeup по-прежнему отбрасываются баннеры и рекламные изображения.

Архив предназначен для GitHub Desktop и содержит только актуальные файлы проекта — без исторических `UPDATE_v*.txt`, `.DS_Store` и прочего мусора.
